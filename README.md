## 如何安装该 Skill

将下面这段提示词复制给 Codex：

```text
请帮我安装这个 Codex Skill，并确认安装成功：
https://github.com/flyl1u/fly-favicon
```

## 安装后如何使用

在 Codex 中先输入 `@` 并选择 `fly-favicon`，再指定风格，或让它根据网站风格探索。

**指定风格：**

```text
为该项目探索标签页图标，尝试小猫、小狗和人物头像，只画头部，
使用像素、贴纸和几何风格，最后生成可点击试用的交互对比页。
```

**根据网站风格探索：**

```text
根据当前网站的内容、配色和风格，探索 10 种标签页图标，
最后生成可点击试用的交互对比页。
```
